7. UNDERSTANDING SIGNAL FLOW
================================================================================

Your Urdu input: "G-10 mein pani bhar gaya hai, gaariyan phans gayi hain"
(Water flooded in G-10, vehicles stuck)

Flow:
  1. Frontend sends signal to /api/v1/ingest
  2. Backend receives → Gemini classifies
     - Detects: flooding, vehicle impact
     - Sets type: urban_flood
     - Sets severity: 4/5
  3. Backend creates Crisis object
  4. Backend runs simulation
     - Simulates: emergency response → reduced impact
  5. Frontend polls /api/v1/crises and /api/v1/simulations
  6. Results display on UI

Current status: Using FALLBACK (Gemini quota) = mock classification
Real AI: Would use actual Gemini API for classification

================================================================================
9. TROUBLESHOOTING
================================================================================

Problem: Signal injected but nothing appears
  → Check backend logs for errors
  → Refresh browser (F5)
  → Wait 3 seconds - backend needs time to process

Problem: "Gemini API error: 429 RESOURCE_EXHAUSTED"
  → Normal - Gemini free tier has 20 requests/day quota
  → System automatically uses fallback mock (still works)
  → To get real AI: Upgrade Gemini to paid plan

Problem: Map shows only text list, not actual map
  → Expected on web browser
  → Google Maps works better on mobile APK
  → Feature will work when we build APK

Problem: Simulation panel shows "No active simulations"
  → Inject a signal first
  → Wait 3 seconds
  → Refresh browser
